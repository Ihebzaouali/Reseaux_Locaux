# Configuration MQTT et Node-RED

Ce projet utilise MQTT avec l'authentification Mosquitto : un **nom d'utilisateur et un mot de passe sont obligatoires**.

## Importer les flows Node-RED

1. Importer les flows Node-RED.
2. Modifier les nœuds MQTT :
   - Adresse IP du broker
   - Nom d'utilisateur
   - Mot de passe
3. Cliquer sur **Deploy**.

> L'authentification MQTT (nom d'utilisateur / mot de passe) est obligatoire.
